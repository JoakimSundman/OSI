# OSI
Network OSI model program

A basic program for studying the OSI network model.

The explanations and some examples for the layers are from: https://www.youtube.com/@LearnCantrill

Input: OSI layer 1-7. Follow-up is protocols like TCP and UDP. 

Output: Details of chosen layer with examples. Protocols are detailed with layer specific 
        information and general information on the inner workings of the protocols.

Each layer is stored in data/layers osi-X.md, 1 <= X <= 7 (e.g. osi-4.md)

Each protocol is stored in data/protocols protocol.md (e.g. tcp.md)
